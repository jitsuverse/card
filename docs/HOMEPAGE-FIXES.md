### 3번 방법 — A안 확정 (2026-10-19 사용자): 다 만든 뒤 겹친 카드만 다시

키트 엔진 `lib/cardkit/engine/render.js`(동기화로 들어감)에 함수가 있다 — DOM 없이 서버(Node)에서 쓴다.

- `kitMainPart(html)` → 카드의 주 도식 클래스(`k-areas`, `k-vs` …, 표지는 `null`). `.k-body` 바로 아래 첫 부품, 보조 부품(`k-hero` · `k-row` · `k-label` …)은 건너뜀. 예시 덱 255장 모두 판별.
- `kitRepeatedCards(htmls)` → 앞 카드와 주 도식이 같은 **뒤쪽** 카드 `[{ index, part, avoid }]` (`avoid` = 덱에서 이미 쓴 도식 전부).
- `kitAvoidNote(avoid)` → 다시 만들 카드 요청 끝에 붙일 문구.

`generateKitDeck`에서 병렬 생성이 끝난 뒤:

```js
import { kitRepeatedCards, kitAvoidNote } from './engine/render.js';
let htmls = raw; // 병렬로 만든 카드들
for (let round = 0; round < 2; round++) {             // 다시 만들어도 겹치면 한 번 더까지만
  const rep = kitRepeatedCards(htmls);
  if (!rep.length) break;
  const again = await Promise.all(rep.map((r) => one(r.index, { instruction: kitAvoidNote(r.avoid) })));
  rep.forEach((r, k) => { if (again[k]) htmls[r.index] = again[k]; });
}
```

(`one`에 추가 지시를 넘기는 자리는 `buildKitCardRequest`의 `instruction` — '이 부분만 다시'와 같은 칸. 실패한 카드는 원래 카드를 그대로 둔다.) 비용은 겹친 카드 수만큼만(대개 0~2장). 키트 검사(`kit-check`)도 같은 함수로 예시 덱의 반복을 잡는다.

### 4번 방법 — 그린 뒤 넘침 재기

넘침은 화면에 그려야 잴 수 있어서 **브라우저(결과 화면)**에서 잰다. 키트 엔진에 함수가 있다(동기화로 들어감):

- `measureKitOverflow(cardEl)` — `lib/cardkit/engine/fit.js`. 보정(`fitKitCard`)까지 끝난 카드 요소를 받아 `{ body, panel, px }`(카드 1080px 기준, 줄여 그려도 같은 값). `px > 0`이면 넘침 — 도식이 콘텐츠 영역보다 길거나(`body`) 흰 도형 밖으로 글자가 나감(`panel`). kit-check와 같은 기준. 시험: 일부러 넘친 카드 201px, 정상 카드 0.
- `kitOverflowNote(px)` — `lib/cardkit/engine/render.js`. 다시 만들 때 요청 끝에 붙일 문구(항목 수 줄이기 · 설명 한 줄 · 세로로 덜 긴 부품, 제목·부연설명은 그대로).

흐름:

1. 생성 직후 결과 화면에 카드를 다 그리고 **웹폰트·사진을 불러온 뒤**(`document.fonts.ready` + 이미지 load) `fitKitCard` → `measureKitOverflow`.
2. 넘친 카드만 '이 부분만 다시'와 같은 경로로 **자동으로 한 번** 다시 만든다 — `instruction: kitOverflowNote(px)`. 그 섹션에는 '카드를 다듬는 중' 표시.
3. 다시 재서 또 넘치면 자동으로 더 하지 않고, 섹션 머리에 **'카드가 넘쳐요 — 이 부분만 다시'** 안내만 띄운다(무한 반복 · 비용 방지).
4. 원장님이 폰트·스타일을 바꿔서 넘친 경우(생성 직후가 아닐 때)는 자동으로 다시 만들지 않고 3번 안내만.

비용은 넘친 카드 수만큼만(대개 0장). 3번(반복 도식)과 같이 쓰면 순서는 반복 도식 정리(서버) → 화면에 그림 → 넘침 재기(브라우저).

```js
// generateKitCards — 표지 먼저, 나머지는 그 뒤 병렬

```
