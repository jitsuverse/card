# 디자인·개발 상세 기록

CLAUDE.md에는 핵심 규칙만 남기고, 규칙이 생긴 이유·세부 수치·개발 기록은 여기에 둔다. 해당 영역(부품·fit.js·아이콘·옵션 패널 등)을 고칠 때만 읽는다. "사용자 확정"은 사용자가 직접 정한 규칙이라 바꾸기 전에 물어본다.

```
assets/             공용 엔진 (config.js 토큰, render.js, card.css, fit.js, icons.js, phosphor.js, cutout.js)
panel/              왼쪽 옵션 패널(panel.js)과 화면 스타일(app.css)
kit/                부품 키트 (index.html, main.js, kit.css, cards.html, PARTS.md, examples/, gallery/)
scripts/            kit-check.mjs(검사) · kit-shot.mjs(사진) · kit-lib.mjs · serve.py
```

## 구조

- **카드 = `.kcard`**, 부품 = `.k-*` 이름공간(`kit/kit.css`). 카드마다 부품(창·말풍선·게이지·블록 쌓기 등)을 조합하거나 새 사물을 그려 HTML을 직접 설계한다.
- **엔진(`assets/`)이 맡는 것**: 옵션 → CSS 변수(`render.js`의 `themeVars`), 카드 배경 판(`cardBackground`), 책 목업·사진 틀·강사 상반신(`bookMockup`·`photoFrame`·`teacherFigure`), 2D 아이콘(`icons.js`)·Phosphor 아이콘(`phosphor.js`), 글자 간격 보정(`fit.js`), 사진 배경 제거(`cutout.js`). 표지·사진 틀·책 목업 모양은 `assets/card.css`.
- **카드 HTML에는 자리만 둔다**: `<div data-photo="cover|book|teacher|photo" data-slot="이름" data-caption="캡션">`(cover는 `data-icon`으로 아이콘 지정, teacher는 카드 바로 아래 자식), 2D 아이콘은 `<i data-icon2d="이름">`. `kit/main.js`가 엔진 함수로 채운다. 표지는 `class="kcard layout-cover"`에 `.cover-tag`·`.title`·`.sub`.
- **왼쪽 옵션 패널**: `panel/panel.js`(내 스타일·폰트·컬러·도형 모양·도형 스타일·본문 카드 배경·교재 목업·표지 이미지). 값은 `themeVars`로 `#deck`에 CSS 변수로 들어가고, 옵션을 추가·수정하면 `kit/kit.css`의 "왼쪽 옵션 연결" 부분도 맞춘다.
- **내 스타일**(5칸): 현재 스타일 옵션(`STYLE_KEYS`)을 브라우저 localStorage(`cardnews.myStyles.v1`)에 저장·불러오기. 새 스타일 옵션을 추가하면 `STYLE_KEYS`에도 넣는다.
- **부품 목록은 `kit/PARTS.md`**: 카드를 새로 설계할 때는 kit.css 전체 대신 이 목록을 읽는다(토큰 절약). 부품을 추가하면 이 목록에도 한 줄 넣는다.

- **지금 기준 (2026-10-14, 여러 번 조정 끝에 사용자 확정)**: CLAUDE.md '카드뉴스 만들기' 1~4(주 도식 + 보조 + 한 줄 요약, 시각 30% · 정보 70%, 글 넉넉히), 기준 덱 `kit/examples/english-grammar.html`.

- 새로 그린 부품은 크게(`--scale 0.5` 이상) 보고 겹침·빈 공간을 다듬는다. 카드형 배경·어두운 배경도 확인한다.

## 글자

- 글자 크기는 `TYPOGRAPHY.size`의 5단계만: display 96(표지 제목) · title 68(카드 제목·강조 숫자) · heading 46(항목 제목·표지 부제·부연설명) · body 38(본문) · caption 32(`※` 참고사항에만). `kit/kit.css` 맨 아래 "글자 크기" 목록에서 부품 역할마다 하나를 정하고, `cards.html`에는 글자 크기를 직접 쓰지 않는다.
- 자간 -3%는 `.kcard *`에 `var(--ls)`(요소마다 자기 글자 크기 기준). 줄간격은 "줄간격" 목록에서 부품 역할별로 `--lh-title`(130%)·`--lh-body`(150%), 큰 숫자만 110%.
- 굵기: 카드 제목 Bold(`headlineWeight`), 그 밖의 제목 역할 Semibold → 없으면 Bold(`titleWeight`), 본문 Regular. 폰트를 추가할 때는 `FONTS`의 `weights`에 실제로 불러오는 굵기를 적는다.
- **제목 폰트는 카드 제목과 큰 숫자에만**: 표지·본문 카드 제목, 강조해 보여주는 숫자 값(46 이상). 항목 제목·라벨·표 머리·단계 이름 등 나머지는 모두 본문 폰트이고, 세미볼드도 본문 폰트 기준(`--title-weight`). kit-check가 검사.
- **글자 색은 굵기와 짝**: 세미볼드 이상(제목·라벨·이름·순위·표 머리) = 제목 컬러, 보통 굵기(본문·값·설명) = 본문 컬러. 예외는 메인 컬러 강조 글자와 메인 컬러 바탕 위 글자뿐. kit-check가 검사.
- 날짜·기간 같은 짧은 라벨은 제목 글꼴·크기를 쓰지 않는다 — 본문 크기 + 세미볼드. '라벨 | 값' 형태(전화·위치 등)도 라벨은 본문 크기 + 세미볼드, 값은 본문.
- 말한 사람("중1 학생" 등 작성자 표시)은 라벨 역할 → 본문 크기 + 세미볼드 + 제목 컬러.
- 같은 성격의 항목(목록·단계·특징 등)은 줄 수·길이를 맞춘다. 한 항목만 2줄 ✗.
- 글자 간격 자동 보정(`fit.js`의 `fitTextGaps`): 폰트마다 글자가 줄 상자 안에서 차지하는 높이가 달라, 줄 상자 기준 여백만으로는 제목↔부연설명 간격이 폰트마다 달라진다. 렌더 후 캔버스로 실제 글자 윤곽을 재서 `INK_GAPS`(프리텐다드 기준: 본문 카드 제목→부연 36, 표지 태그→제목 44, 제목→부제 44) 거리가 되도록 여백을 조정한다. 위아래 나눔(`split`)에서는 `fitSplitHead`가 흰 제목 영역의 '제목 글자 위 여백 = 부연설명 글자 아래 여백'이 되도록 맞춘다. 웹폰트 로드 후 다시 실행해야 정확하다.

## 여백·배치

- 본문 카드 머리는 항상 **제목 2줄 + 부연설명 1줄**.
- 본문 카드 콘텐츠 여백은 위=아래(180), 왼쪽=오른쪽 대칭. 좌우는 단색·위아래 나눔 128(`PANEL_TOKENS.padding`), 판 배경(카드형·테두리형)은 판 안이 좁아 보이지 않도록 168(`panelPadding`). 위아래 나눔도 흰 제목 영역·본문 영역 각각 위=아래.
- 표지 글자는 인스타 격자 썸네일(1:1)에서도 다 보이도록 가운데 1:1 영역(y 180~1260) 안, 그 영역에서 96px 안쪽(`COVER_TOKENS`). 표지 아이콘·교재 사진도 1:1 영역 안(`--cover-inset`). 강사 사진만 상반신을 카드 아래 끝에 세우는 모양이라 예외. 표지 정렬 가운데(`coverAlign`)는 글자·이미지를 한 묶음으로 1:1 영역 한가운데에 쌓는다. 표지 배경 메인 컬러(`coverBg`)면 글자 강조색은 `--on-main`.
- 콘텐츠 세로 가운데(2026-10-15 사용자 확정): 콘텐츠 영역은 부연설명 바로 아래부터 카드 맨 아래 끝까지로 보고, 도식 묶음을 그 가운데에 둔다. 예전에는 본문 위 간격(88)과 카드 아래 여백(180) 사이에서 가운데를 잡아 46px 위로 떠 보였다. `.k-body`의 아래쪽을 카드 아래 여백 안으로 늘려(margin-bottom: 88 − 180) 위아래 간격을 같게 만든다. 이때 기존 카드는 모두 위아래 최소 130px 이상 여백이 남았다. 그다음 사용자 요청으로 시각 보정: 수학적 가운데는 아래로 처져 보여 `--optical-lift`(24px)만큼 위로 옮긴다 — margin으로 깎으면 상단 강조 배경의 꽉 찬 카드가 2~5px 넘쳐서, 영역은 그대로 두고 `translate`로 보이는 위치만 옮긴다(PNG 내보내기도 같은 위치).
- 자연스러운 크기: 영역을 채우려고 도형을 늘리지 않는다. 도식은 내용만큼의 크기로 영역 가운데에. 그래프처럼 높이가 정보인 것만 영역을 꽉 쓴다.
- 여백 채우는 우선순위: ① 정보 구조를 바꿔 의미 있게 채운다(핵심 결과 하나를 큰 숫자로 먼저 보여주고 나머지를 받치는 식) ② 그래프는 높이가 정보면 영역을 쓴다 ③ 그래도 남으면 내용과 분명히 맞는 2D 아이콘. 도형을 그냥 늘리거나 의미 없는 아이콘으로 채우지 않는다.
- 콘텐츠 영역 전체를 흰 도형 하나로 감싸지 않는다 — 도형은 항목·칸 단위로. 예외: 내용이 한 덩어리뿐이라 상자 없이 두면 허전한 경우(큰 인용 등)는 내용 크기의 흰 도형 하나.
- 가로 도식이 좁아 글이 어정쩡하게 줄바꿈되면 세로 배치가 낫다.
- 도식이 영역을 넘치면 잘리지 않고 드러나도록 `.k-body > *`는 줄어들지 않게 해 두었다(kit-check가 넘침을 잡는다).

## 도형·색

- 도형은 기본 흰색(`--shape-fill`). 메인 컬러 면은 강조 한 곳에만. 겹침·단계 차이는 다른 색 대신 흰색과 옅은 메인 컬러(16%·30%)를 섞는다(전부 흰색이면 단조로움).
- 큰 도형(카드·박스)은 도형 모양 옵션(`--r-lg`, `--r-sm`)을 따르고, 동그라미는 번호 원·아이콘 배경 같은 작은 표식에만(`border-radius: 50%`, 모양 옵션과 관계없이).
- 판 배경(카드형·테두리형): 판 위 도형 = 배경색, 그 안의 도형(말풍선·태그·막대·블록) = 흰색으로 번갈아 칠한다. 같은 색이 겹쳐 구분이 안 되거나 단조로워지지 않게.
- 어두운 배경(밝기 < 0.5): 흰 도형은 흰색 10%의 유리 도형(`SHAPE_TOKENS.darkFill`)이 되고 도형 안 글자는 원래 규칙을 따른다. 판 배경은 도형이 배경색이라 글자를 밝게 바꾼다(`shapeTextColors`). 바탕에 메인 컬러 조명 1개(오른쪽 위, 24%, `--bg-glow`) — 2개·진한 조명은 사용자가 거절. 밝은 배경에는 그라데이션 없음.
- 구분선·연결선 굵기는 고정값 대신 `var(--line-width)`(도형 스타일 옵션). 선·점 장식은 얇고 차분하게(2px 회색 선, 작은 흰 원 + 메인 테두리) — 굵은 색 선·배경색 띠는 촌스럽다는 피드백.
- 도식 사이 화살표는 Phosphor `caret-*`(Bold)를 회색(`--arrow`: 본문 색 38% + 배경)으로. 메인 컬러·CSS로 그린 화살표 ✗.
- 줄 목록은 위·아래 구분선으로 닫되, 도형 안에 들어간 목록은 맨 아래 선을 빼고 도형 가장자리로 닫는다.
- 막대·책등 같은 그래프 도형에 기준선·장식 띠 같은 정보 없는 선 ✗.

## 아이콘·사진

- 번호 동그라미(`number-circle-1~9`)·체크 동그라미(`check-circle`)는 Phosphor Icons(Fill, MIT)를 인라인 SVG로(`assets/phosphor.js`). 추가할 때는 @phosphor-icons/core의 fill SVG 경로를 `PHOSPHOR`에 넣는다. 그 밖의 그림 아이콘은 `icons.js` 2D 세트. 3D·Material 아이콘 ✗.
- 텍스트 옆 아이콘은 원 지름을 옆 글자 크기의 약 1.2배로(본문 38 옆 → 원 46, 46 옆 → 원 55; Phosphor 상자 = 원 ÷ 0.81), 아이콘↔글자 간격 12~20px.
- 작은 자리의 2D 아이콘에는 바탕 원을 두르지 않는다. 바탕 원은 큰 아이콘이 주인공인 자리에만.
- 강사 사진 배경 제거: `assets/cutout.js`(Google MediaPipe 사람 분할, Apache 2.0). 모델·라이브러리를 CDN(jsdelivr, storage.googleapis.com)에서 받으므로 네트워크가 필요하다. 한 사람이 나온 인물 사진용.
- 사진 위에 캡션 칩을 띄우지 않는다 — 캡션은 사진 넣기 전 자리 안내에만.

## 정지 이미지

- 접기·펼치기 화살표, 탭, 더보기 같은 조작 UI 상태를 그리지 않는다(Q&A는 질문·답을 모두 펼친 상태로).
- 화면형 부품(가짜 창·앱 화면)에는 책 제목·쪽수·날짜·참여자 같은 세부 텍스트를 넣지 않는다 — 창 머리에는 점 3개만. 이름 첫 글자 동그라미(아바타)나 레벨 같은 상태 태그도 ✗ — 말풍선은 좌우 위치·색으로 말한 사람을 구분한다.

## 실행·검사

`python3 scripts/serve.py` → http://localhost:5173/ (자동으로 /kit/). ES 모듈이라 file:// 로는 안 열린다. serve.py는 브라우저 캐시를 끄는 헤더를 붙여 수정 사항이 바로 보인다.

검사: `node scripts/kit-check.mjs` (폰트 21종 × 배경 4 — 넘침·5단계 밖 글자 크기·자간·줄간격·직접 지정·글자 색·제목 폰트·페이지 오류, 약 15초). 만드는 중에는 `--quick`(약 5초), 기존 부품·공통 CSS를 고쳤으면 `--all`(예시 덱까지).

## 옵션 이름

화면에 보이는 이름(쉬운 우리말): 도형 모양 각진형/둥근형, 도형 스타일 기본/그림자/테두리(세부: 테두리 굵기·색), 본문 카드 배경 기본/카드형/테두리형/상단 강조, 교재 목업 정면/책등/옆면/옆면 넓게. 코드의 id(`solid`·`panel`·`outline`·`split` 등)는 그대로.
